# Neutral style — mood & discipline

**Register:** clean, editorial, generic. A sensible default that reads as
"a well-set deck" without carrying any house identity. When a deck should
look like a specific brand, use a house-style or bring-your-own pack
instead.

**Fonts:** Fraunces (display/titles) + Inter (body, labels, footer).
Serif titles carry the argument; the grotesk carries supporting text.

**Accent:** a restrained slate (`--accent`), used sparingly — title-rule,
card markers, header dots, closing rule. Never body text in the accent;
never a large accent fill.

**Light/dark rhythm:** alternate. No more than 3 light slides in a row,
no more than 2 dark. Dark layouts (verdict, pull-quote, cover, section
divider, half-bleed) punctuate the light editorial run.

**Cover:** a quiet dark background with a faint slate bloom
(`--cover-bg`), title set large. No logo, no gradient identity.

**Promotion:** this pack ships no `template.html`, so Stage 4b promotes
only within the baseline family (cover / editorial / verdict / closing)
and the keynote family. That is the intended scope for a generic pack.
